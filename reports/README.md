# Reports

This directory contains committed, redacted findings, decision records,
comparison results, and human-review outputs for Phase 0. Reports summarize or
evaluate work; they are not raw captures, normalized intermediates, or test
fixtures.

Every report must be reviewed before commit and must follow the naming,
timestamp, metadata-sidecar, collision, and redaction rules in
[`data/README.md`](../data/README.md). Keep unredacted or not-yet-reviewed
reports under the ignored `data/private/` directory. Do not add real private
league or manager data to a report.
